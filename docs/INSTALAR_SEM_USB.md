# Instalar o Geo Mania sem cabo

## Instalação manual

1. Localize o APK atual em `entrega/GeoMania-0.6.0-debug.apk` (também disponível como `GeoMania-debug.apk`). Instale como atualização sobre a versão anterior, sem desinstalar, para preservar o recorde do GeoMatch.
2. Transfira esse arquivo do computador para o celular usando um meio que você já utiliza, como armazenamento pessoal na nuvem ou transferência de arquivos pela rede. Nenhum arquivo é enviado automaticamente por este projeto.
3. No celular, baixe o arquivo completo e abra-o pelo gerenciador de arquivos.
4. Se o sistema solicitar, autorize a instalação por esse aplicativo de origem e confirme a instalação. Os nomes dos menus variam conforme o fabricante e a versão Android. Consulte as [orientações oficiais de instalação](https://support.google.com/pixelphone/answer/7391672?hl=pt-BR).
5. Abra **Geo Mania**. Teste as telas e uma partida em modo avião.

Se a instalação for bloqueada, anote a mensagem exata e a versão Android antes de alterar outras configurações. Algumas versões e aparelhos têm regras adicionais para desenvolvedores não verificados.

## Depuração sem fio opcional

Android 11 ou superior oferece depuração sem fio, sem conexão USB inicial. Computador e celular precisam estar na mesma rede Wi-Fi. Ative **Depuração sem fio** nas opções do desenvolvedor e use o pareamento por código do aparelho. O procedimento oficial está na [documentação do Android Debug Bridge](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi).

O pareamento exige o endereço, a porta e o código temporário mostrados no próprio aparelho. Não é necessário publicar esses dados nem expor a porta do telefone na internet.

## O que conferir

Use `VALIDACAO.md` para registrar instalação, navegação, conclusão da partida, persistência do recorde, rotação e fonte grande. O primeiro APK é uma versão debug para avaliação.
